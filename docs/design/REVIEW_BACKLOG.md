# REVIEW_BACKLOG.md

## 使い方
自律レビューの巡回対象。1周につき1画面・1テーマを扱う。レビュー終了時に最終レビュー日、直近の指摘、状態を更新する。

状態は `要レビュー` / `保留` / `完了` のいずれか。

| 対象画面 | 最終レビュー日 | 直近の指摘 | 状態 |
|---|---|---|---|
| ホーム | 未レビュー | なし | 要レビュー |
| 市場・銘柄分析 | 未レビュー | なし | 要レビュー |
| 銘柄詳細 | 未レビュー | なし | 要レビュー |
| 取り込み（会話を取り込む） | 未レビュー | なし | 要レビュー |
| リマインダー一覧 | 未レビュー | なし | 要レビュー |
| リマインダー詳細 | 未レビュー | なし | 要レビュー |
| 設定 | 未レビュー | なし | 要レビュー |
| 注目ポイント編集シート | 未レビュー | なし | 要レビュー |
| 指標編集シート | 未レビュー | なし | 要レビュー |
| 業績推移編集シート | 未レビュー | なし | 要レビュー |

## 保留課題

### 配色の見直し
`--navy:#123a5e` が重い。タブバー・バッジ・グラフ・チップに波及するため、実装前に使用箇所の洗い出しと案の提示が必要。

**状態:** 保留
**境界:** トークン変更＝ユーザー確認が必要。

### 色トークンの逸脱検査を design.js に追加
現在 `test/e2e/design.js` は色を一切検査していない。`:root` 定義外の色を使ってもテストが通る。

**状態:** 要対応
**境界:** `test/` 配下の追加のみなので自律判断可。

### esc / escArg の誤用検査を design.js に追加
現在 `test/e2e/design.js` は使い分けを検査していない。`onclick` 内で `esc()` を使う等の誤用があってもテストが通る。

**状態:** 要対応
**境界:** `test/` 配下の追加のみなので自律判断可。

現在 spacing 契約は `gap` にのみ適用されている。padding / margin はトークン外の値が正当な実装として存在する(入力欄の `padding:10px 12px` など)。統一するかどうかは未決。

**状態:** 保留
**境界:** トークン範囲の拡張＝ユーザー確認が必要。
