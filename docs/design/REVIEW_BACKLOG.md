## ホームの未解決事項(2026-08-09 の採点で検出)

11次元採点の詳細は `DECISIONS.md` の同日エントリを参照。次周以降のテーマ候補。

1. **実運用摩擦=0 / 期限切れからリマインダー本体へ行けない** — 「今週の予定」の行は `openReminder()` に飛べるのに、最も操作が必要な「期限切れ」はコピーボタンしか無く、再スケジュール・休止・削除に到達できない。最優先。
2. **Accessibility=1 / `.hint` のコントラスト不足** — `--ink3`(#8b95a1)が `--red-bg` 上で 2.54:1、`--navy-bg` 上で 2.62:1。WCAG AA(4.5:1)にもAA-large(3:1)にも届かない。`--ink2` なら 4.90〜5.06:1 で解消する。**これは今回の変更以前から存在する**(navy-bg 側も不合格)。`.hint` は全画面で使うため影響範囲の確認が必要。
3. **一貫性=1 / 空表現とゼロ状態** — 同一画面内で「なし」×3 と「予定はありません」×1 が混在。またホームだけ `.empty` によるゼロ状態の案内が無い(市場・銘柄分析/取り込み/リマインダー一覧にはある)。新規ユーザーが「(0) なし」を4つ見るだけになる。
4. **Color=1 / 赤トークンの意味の衝突** — `--red-bg` が `remCatCls()` の「需給確認カテゴリ」と、ホームの「期限切れ状態」の両方を指す。
5. **認知負荷=1 / 静かな日の画面上部** — 期限切れも今日も0件の日(通常はこれ)に、空の2区分が画面最上部を占有してから内容に到達する。
